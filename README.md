# Who is right? ⚖️

한국어·영어를 지원하는 일상 속 작은 AI 법정. 2–6명의 입장을 입력하고 책임과 화해 방법을 확인합니다.

## 실행

Node.js 24 이상이 필요합니다. 제공된 네트워크 프록시를 사용하도록 시작 명령에 `--use-env-proxy`가 포함되어 있습니다.

```sh
npm ci
npm run dev
```

기본 포트는 3000입니다. `PORT`로 변경할 수 있습니다.

```sh
npm run build
npm start
```

## 실제 AI 판결

[Google AI Studio](https://aistudio.google.com/apikey)에서 **결제가 연결되지 않은 무료 등급 프로젝트**의 API 키를 발급받고, 환경 설정의 `GEMINI_API_KEY`에 안전하게 입력하세요. 키를 채팅·프론트엔드·Git에 넣지 마세요. 서버는 `.env`를 자동으로 읽지 않습니다. 키를 설정한 뒤 서버를 다시 시작하세요.

기본 모델은 `gemini-3.1-flash-lite`입니다. `GEMINI_MODEL`로 변경할 수 있습니다. 현재 모델의 지원 여부와 무료 등급 적용은 [공식 요금표](https://ai.google.dev/gemini-api/docs/pricing)와 프로젝트에서 확인하세요. 이 환경에서는 공식 요금표 접근이 불가능하여 최신 한도를 확인하지 못했습니다.

앱 전체에 하루 20회(UTC 기준), 요청 사이 30초 제한을 적용합니다. 실패한 요청도 포함하며 자동 재시도나 유료 모델 전환은 없습니다. 횟수는 `.local/ai-usage.json`에 저장되어 서버를 재시작해도 유지됩니다. 단일 서버용 제한이며 여러 서버 간에는 공유되지 않습니다. **요청 제한만으로 무료 사용을 보장하지는 않습니다. 결제를 연결한 프로젝트의 키는 사용하지 마세요.**

키가 없으면 **데모 모드**로 동작합니다. 예시 판결은 입력을 분석하지 않습니다. 실제 Gemini 호출은 키 입력 후 검증해야 합니다.

AI 사용 시 사건 내용이 Google Gemini로 전송됩니다. 무료 등급의 데이터 이용 정책을 확인하고, 민감한 개인정보는 입력하지 마세요. 사이트는 사건 내용을 저장하지 않습니다. AI 판결은 대화와 재미를 위한 참고이며 법률 자문이 아닙니다.

## 기능

- 2~6명 참여, 역할·증언·사건 배경 입력
- 한국어 / English 전환 및 언어 설정 유지
- 3가지 예시 사건
- AI 판결, 책임 비율, 이유와 화해 제안
- 반응형 디자인, 키보드 접근 가능한 판결 창

## 배포 전

현재 서버는 개인 개발·시연용입니다. 공개 운영에는 사용자 인증과 여러 서버에서 공유되는 요청 제한이 필요합니다.

## Render에서 main 자동 배포

[Render 배포 시작](https://render.com/deploy?repo=https://github.com/MinseoK2626/WhoIsRight-)

Render에 로그인하고 위 링크로 Blueprint를 생성하세요. `render.yaml`은 무료 Node 웹 서비스, `main` 커밋 자동 배포, 빌드와 시작 명령 및 상태 확인 경로를 설정합니다. Render에서 `GEMINI_API_KEY` 값을 별도로 안전하게 입력하세요. Codex의 비밀 값은 Render로 자동 복사되지 않습니다. 키는 저장소에 포함되지 않습니다.

무료 서비스의 휴면·재배포·재시작 시 로컬 파일이 사라질 수 있어 하루 요청 횟수가 초기화됩니다. 따라서 앱의 횟수 제한은 요금 방지 장치가 아닙니다. 결제가 연결되지 않은 Gemini 무료 프로젝트만 사용하세요. 안정적인 누적 제한이 필요한 공개 서비스에는 외부 저장소가 필요합니다.

설정 파일을 커밋하는 것만으로 서비스가 생성되지는 않습니다. Render 계정에서 최초 생성 및 GitHub 접근 연결을 완료해야 합니다. 실제 서비스 URL은 Render가 발급하며 이 프로젝트에서 임의로 정하지 않습니다.

## GitHub Pages (데모 화면)

저장소 Settings → Pages → Source에서 **GitHub Actions**를 선택하세요. `.github/workflows/pages.yml`이 `main`의 변경을 빌드하여 배포합니다. 예상 주소는 https://minseok2626.github.io/WhoIsRight-/ 입니다. Actions의 배포 성공 이후 접속하세요.

GitHub Pages는 Node 서버와 비밀 키를 실행하지 않습니다. 이 주소에서는 명시적인 데모 판결만 제공됩니다. 실제 AI 판결은 Render처럼 서버를 지원하는 호스팅의 주소에서 사용하세요. API 키를 GitHub Pages 빌드 변수나 프론트엔드에 넣지 마세요.

## 재판 게임 연출

오리지널 SVG 변론 캐릭터·판사, CSS 모션, 이의 있음 팝업과 판결 도장 연출을 제공합니다. 상단 소리 버튼을 켜면 Web Audio로 짧은 효과음을 생성합니다. 소리는 기본 꺼짐이며 클릭 이후에만 재생됩니다. 기기의 동작 줄이기 설정을 존중합니다. 외부 캐릭터 이미지·음원이나 GIF 다운로드가 필요하지 않습니다.

BGM 버튼은 96 BPM의 오리지널 합성 재판 음악을 켭니다. 저음의 두둥두둥 리듬과 단조 화음·짧은 음형을 직접 합성한 MP3 파일로 재생하며, 기존 곡의 녹음·샘플을 사용하지 않습니다. 효과음과 독립적으로 켜고 끌 수 있고 볼륨을 조절할 수 있습니다. 자동 재생하지 않으며 다른 탭으로 이동하면 재생을 멈춥니다.

BGM은 `public/audio/courtroom-original.mp3`에 포함되어 GitHub Pages에서 직접 재생됩니다. 기본 음량은 65%이며 🔊 버튼으로 테스트음을 확인할 수 있습니다. 재생 실패 시 화면에 원인을 표시합니다. 음원 재생성 스크립트는 `scripts/make-bgm.py`이고, 재생성에만 Python/numpy 및 ffmpeg가 필요합니다.
